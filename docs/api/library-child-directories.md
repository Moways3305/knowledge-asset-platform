# 知识库三级目录

`POST /api/v1/knowledge/directories` 创建一个立即生效的三级目录，不修改或发布全局命名配置草稿。请求字段：`scope`（company/project）、`project_id`（仅项目必填）、`parent_key`（启用的同范围标准分类）、`display_name`（1–80 个合法字符）。成功返回 201 和 `directory_key`、`name`。

公司库仅当前有效的总经理、咨询总监可创建；项目库仅当前项目的有效项目经理可创建。纯系统管理员、普通成员、其他项目经理不能创建。目录不授予资料权限。

项目子目录独立绑定项目，不会成为其他项目的全局模板。继承创建时父分类默认密级；目录浏览、上传命名、资料编辑和检索复用正式目录校验。只允许标准分类下面一层子目录，同父级大小写无关重名返回 409，跨库、跨项目引用或四级目录返回 422。

创建与审计同事务写入，数据库唯一约束保护并发同名创建。创建与全局发布共用首个不可变发布版本作为稳定锁锚点，读取当前正式配置后再校验；全局发布不能停用已有子目录的父分类，也不能发布与直接创建目录重名的子目录。已有未发布草稿不因新建操作改变。

部署需运行 Alembic 0079 迁移。历史版本目录与既有公司库草稿发布入口继续兼容；页面新建操作不需要全局发布权限。
