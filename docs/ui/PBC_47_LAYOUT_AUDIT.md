## 共享执行规则

- 页面：`ProductPage` / `.product-page`，最大宽度与垂直间距统一。
- 标题：`PageHeader` / `.product-page-header`，只保留一句说明和一个主动作区。
- 内容：一个业务分组一个边框；禁止卡片嵌套卡片。
- 列表：筛选、数量、刷新、主动作位于 `PageToolbar`；表格在 390px 内部滚动，不撑破页面。
- 状态：普通数量中性；仅成功、警告、失败使用绿/黄/红。
- 说明：技术说明、治理原则和低频诊断默认放进 `details.product-disclosure` 或帮助页。
- 安全：页面与截图不得出现 storage ref、token、API key、base URL、raw model id、WeKnora id 或原始错误。
