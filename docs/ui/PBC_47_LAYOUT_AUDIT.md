# PBC-47 页面布局审计

本轮以同一套页面宽度、标题、分组、工具栏、状态条、设置行、表格和状态反馈为目标。首批验收页直接迁移到共享组件，其余路由先由共享样式统一基础密度，后续按业务流程逐页替换局部旧结构。

| 页面 / 路由 | 当前问题 | 目标模式 |
| --- | --- | --- |
| 今日工作台 `/` | 快捷入口与统计区密度不一 | 标题 + 紧凑概览 + 单层任务分组 |
| 知识资产 `/knowledge` | 自有 masthead 与其他页面宽度不同 | 共享页面壳 + 搜索工具栏 + 卡片/列表 |
| 资产详情 `/knowledge/:id` | 详情、预览与运维提示层级多 | 知识卡主视图 + 次要技术信息折叠 |
| 我的知识 `/my/knowledge` | 筛选、状态与列表样式独立 | 共享标题 + 工具栏 + 列表/空状态 |
| 上传确认 `/upload` | 步骤与异常信息可能挤占主操作 | 稳定步骤 + 单一主操作 + 就地状态 |
| 待审核 `/review` | 筛选和批量动作缺少固定位置 | 共享工具栏 + 表格 + 详情操作 |
| 原文申请 `/original-access` | 申请状态和动作密度不稳定 | 状态条 + 申请列表 + 明确空状态动作 |
| 项目知识 `/project/:id/knowledge` | 与全局知识库版式略有分叉 | 共享页面壳 + 项目上下文工具栏 |
| 项目设置 `/project/:id/settings` | 设置项仍以多种卡片组织 | 单分组内的设置行与统一操作区 |
| 帮助 `/help` | 长内容与目录宽度体系独立 | 共享内容宽度 + 稳定章节导航 |
| 入库管理 `/admin/ingest` | 指标卡、运维卡、说明卡连续堆叠 | 状态条 + 紧凑运维 + 表格主体 + 按需详情 |
| 微盘扫描 `/admin/wecom-scan` | 配置、运行记录与空状态样式独立 | 设置行 + 运行表格 + 产品化状态 |
| 模型管理 `/admin/weknora-models` | 模型种类与默认配置缺少统一层级 | 共享标题 + 表格 + 设置行 + 表单区 |
| 审计日志 `/admin/audit` | 大统计卡和原始技术字段抢占视线 | 紧凑状态条 + 标签页 + 技术详情折叠 |
| 登录风控 `/admin/auth-security` | 配置项对齐和禁用解释不一致 | 设置行 + 明确禁用原因 + 保存操作区 |
| 告警设置 `/admin/alert-settings` | 开关、阈值与说明分散 | 设置行 + 分组保存 + 就地反馈 |
| 人员管理 `/admin/people` | 筛选、人员表和编辑区层级较多 | 工具栏 + 表格主体 + 按需编辑区 |
| 权限管理 `/admin/permissions` | 权限矩阵与说明区视觉语言独立 | 共享分组 + 可滚动矩阵 + 固定操作区 |

## 本轮改动范围

- 直接迁移：入库管理、审计日志、模型管理及默认模型配置、知识资产列表页面壳。
- 共享覆盖：所有 KAP 页面使用统一最大内容宽度、分组边框/圆角、控件焦点与禁用态、表格滚动和 390px 响应式规则。
- 保持不变：路由能力守卫、后端权限、API 契约、任务状态、审计语义、来源追溯和所有管理员动作。
