# KAP 前端设计基线

## 范围与边界

覆盖工作台、知识库与详情、上传、项目空间与问答、审批以及全部管理页面内部布局。

生产路由仍由 `src/App.tsx` 管理，唯一外壳是 `src/layouts/AppLayout.tsx`。
在现有组件树中改造，不增加 legacy、v2 或演示页面；不引入演示数据、固定回答、
假统计或假身份。API、状态流转、审核条件与权限规则保持原样。

重构页面的结构、交互与视觉一律以已确认的新设计为准，旧前端页面不再作为设计参照。
以实际后端接口、返回状态和权限约束核对功能完整性，不能因为旧页面这样排列便沿用布局。
“固定模块导航 + 右侧工作面”是知识相关页面的统一结构；
切换知识资产库、我的知识和知识维护时，入口顺序、位置、宽度与选中反馈必须稳定。
页面内部的搜索、状态筛选、资料列表、空状态和操作也必须按新结构重组，不能只换外壳。

## 导航

- 桌面一级入口为工作台、知识库、项目空间、审批中心、管理中心，按现有能力显示。
- 知识库内组织知识资产库、个人知识、知识维护、上传资料；目录与范围属于资源导航。
- 项目选择使用真实项目 ID 和成员/摘要可见范围；项目内保留概览、知识库、问答、设置。
- 审批中心集中审核待办、已完成、原文申请及授权记录，实际操作仍由原权限决定。
- 管理功能通过模块菜单分组，保留全部获准入口，不把低频管理项铺满全局侧栏。
- 帮助与更新收进页脚菜单；退出登录放入身份菜单。
- 手机底部为工作、知识、项目、审批、我的；全部获准功能在“我的”中可达。
- 详情、问答、上传等专注操作页让出底部位置，避免导航覆盖任务操作。

## 视觉与页面层级

保留原始 MOWAYS Logo，不裁切、不变形。浅灰导航、白色工作面、冷灰画布，
操作蓝 `#3370FF`，分隔线 `#E5E6EB`。状态色只表达真实状态，不把未加入项目的
总经理/管理员误画成错误。去除金色大面积强调、玻璃光效、装饰英雄卡片和重复标题。

标题/分区/正文/辅助信息按 24/16/14/12px 建立层级。间距使用 4/8/16/24/32px，
桌面侧栏约 190px、顶栏 56px。主操作与当前对象放在一起；危险操作单独表达。
表格允许在自身容器内滚动，body 不得横向溢出。

| 页面 | 桌面 | 手机 |
| --- | --- | --- |
| 工作台 | 任务列表为主，项目与近期动态为辅 | 任务优先，字段带标签，次要区域后置 |
| 知识库 | 范围/目录侧栏 + 搜索/结果工作面 | 标题、局部入口、范围、目录、结果依次呈现 |
| 资料详情 | 阅读区 + 资料属性，原文/版本/维护入口保留 | 阅读优先，属性可展开，操作固定底部 |
| 上传 | 紧凑步骤导航 + 当前上传/核对/记录任务 | 按步骤组织，表单与操作不被底部导航覆盖 |
| 审批 | 队列 + 材料/审批进度详情 + 决策区 | 条目化队列，详情抽屉，底部决策按钮 |
| 项目与问答 | 项目页签，问答正文 + 依据侧栏 | 独立问答阅读区，引用在底部抽屉查看 |
| 列表管理 | 横向筛选工具栏 + 表格 + 编辑弹窗 | 标签化条目，筛选换行，编辑用底部弹层 |
| 目录/项目设置 | 有实际层级的侧栏 + 当前配置 | 分区导航与表单重排，保存关系保持明确 |

## 通用组件

页面使用 ProductPage、PageHeader、PageToolbar/FilterBar、PageSection；列表使用
DataTable；状态使用 StatusBadge；表单使用 FormField。CollectionWorkspace 默认
使用筛选工具栏，有真实目录/设置层级时才选择 sidebar。弹层使用现有 DetailDrawer
和 TaskModal，保留焦点管理、关闭、提交锁定与错误反馈。

ModuleNavigation 管理模块入口；项目空间使用真实项目数据；
ResponsiveEvidencePanel 在桌面与手机复用相同安全引用字段，不增加请求或泄露原文。
加载、空状态、禁用和失败原因必须保留。手机可以折叠低频信息，不能删除判断所需字段。

## 验证与安全

- 真实数据加载与现有操作接线，禁止模拟成功。
- 导航与页面守卫沿用 auth/permissions.ts；后端权限始终是权威。
- 覆盖 1440/1920px 桌面和 390px 手机，关键弹层追加 320px 检查。
- 检查长标题、空状态、筛选、详情、关闭/取消、固定按钮与横向溢出。
- 删除已替代结构，运行目标测试、全量前端测试、Lint 与生产构建。
- 浏览器检查在隔离的本地 Docker 预览中进行，不修改生产身份/权限/资料。
- 未配置模型、OnlyOffice 等外部服务时，如实验证不可用提示，不声称外部链路已通过。
- token、API key、存储路径、内部服务 ID 与原始上游错误不进入普通业务 DOM/截图；
  管理员新建助手时仅在明确的凭证展示区域一次性返回凭证，默认遮挡且关闭后清除。
- 原文只在现有授权预览路径展示；身份与敏感配置不写入浏览器本地持久存储。
