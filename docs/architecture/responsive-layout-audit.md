## 复现与修复

知识库在内容区变窄时将 table cell 转为 grid item，但沿用表格单元格的固定 height。原本在表格中可随内容撑高的单元格，变成固定高度块，摘要溢出到来源和更新时间上。在 861、960、1024、1100、1101 CSS 像素窗口复现；修复为卡片单元格使用自动高度。

同样检查空状态：知识库的空状态保留固定高度；项目知识库的空状态还被放入勾选框所在的窄列。空状态在卡片模式下应占满整行，并由内容决定高度。

## 持续验收

`scripts/responsive-layout-audit.mjs` 在现有页面测试的稳定截图点检查整页横向溢出、卡片单元格内部溢出、单元格相互重叠。失败时输出具体路由、场景、宽度及截图。各模块原有的按钮、弹层、导航、权限状态和交互检查继续运行。

默认执行当前测试尺寸；设置 `UI_QA_RESPONSIVE_AUDIT=1` 扩展为 320、360、390、700、701、720、768、860、861、960、1024、1100、1101、1280、1440、1920 CSS 像素，包括断点相邻宽度。960 和 720 也对应 1440 宽桌面在 150% 和 200% 缩放后的等效布局宽度；这是布局等效检查，不是对所有浏览器原生缩放实现的证明。

所有页面测试使用本地模拟接口，截图与报告输出到临时目录，不使用或提交生产数据。人工复核代表性的桌面、窄窗口和手机截图；自动检查不能替代所有视觉判断。
