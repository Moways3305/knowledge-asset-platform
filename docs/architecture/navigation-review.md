# 页面导航审查与约定

审查基线：PR #243 合并后的 `57cd2720`。范围为 `src/App.tsx` 注册的页面、页面内入口、通知和任务入口、登录回跳、历史链接及浏览器历史行为。通过本地代码审查和合成数据的浏览器测试验证；不表示已在生产账号下逐条执行。

## 导航原则

- KAP 的 AI 工作空间入口独立打开；进入工作空间后，Agent 列表、Agent 工作页、通用会话和工具之间在同一标签页切换。
- Agent 业务组件复用现有权限、配置、待办和巡检 API，工作空间父组件持续挂载，保留当前会话、未发送输入和未保存的文档编辑。
- 在 AI 工作空间查看 KAP 资料、模型管理或完整帮助时，明确标识新标签页打开；对照资料和外部认证继续使用有意义的跨页方式。
- 通知和任务必须定位具体业务对象，已结束任务进入可查看结果的位置；目标无权、已删除或不可用时明确提示，不默默打开其他对象。
- 已应用的列表筛选和页码存入 URL，搜索输入草稿保留在本地，提交时一次更新 URL。浏览器前进/后退和详情返回以同一份状态恢复。
- 修改当前页状态使用路由导航，不用整页刷新。身份认证跳转和渲染崩溃恢复保留原生导航。

## 确认的问题与修复

| 原有问题 | 修复行为 |
| --- | --- |
| AI 工作空间的知识维护入口新开旧 KAP 页面 | 使用 `/ai-workspace/agents/knowledge-maintenance`，复用持久工作空间外壳，同标签页进入/返回 |
| 旧维护提醒和书签可能跳出 AI 工作空间 | `/agents/knowledge-maintenance` 保留查询条件和片段，替换式转到新地址；不改历史通知数据 |
| 知识资产库、个人资料、项目资料的筛选/分页只在组件内 | 统一查询状态 helper，详情带完整来源；浏览器 POP、刷新和返回恢复已应用条件 |
| 项目目录的搜索返回后丢失 | 搜索提交状态存入项目目录 URL |
| 项目上传的“返回”跳到全局知识库 | 保存入口来源；直接项目上传链接回该项目资料；个人入口回个人资料 |
| 上传完成/等待审核通知只能找到待处理任务 | 支持本人上传历史按任务 ID 查询，深链显示对应记录及结果；无权记录不返回 |
| 上传者的“查看审批状态”进入审批收件箱 | 定位本人上传历史中的该任务 |
| 删除资料或项目后后退进入已删除详情 | 删除成功替换当前路由，项目删除返回项目目录 |
| 删除最后一个项目后，项目目录被成员关系守卫拦截 | 业务用户可访问空项目目录；具体项目仍要求原有项目权限，后端授权不变 |
| 任务中心只含模块入口，没有业务对象定位 | 后端在已鉴权投影中提供可选 `resource_id`，前端与通知共用严格路由映射 |
| 完成审核没有可查看的具体记录 | 完成任务支持准确打开详情 |
| 原文申请后退到无 `box` 的 URL 时仍停留收件箱 | 页签由 URL 派生，保留项目参数；审批与本人申请入口显式区分 |
| 已处理的原文审批提醒无法查看结果；授权记录返回丢失筛选页码 | 只读详情按当前发现权/审批权验证；授权列表将状态和页码写入 URL，返回保留完整来源 |
| 入库运维和模型迁移通知带 ID 但目标页不消费 | 按授权后的目标 ID 查询/定位；历史或失效迁移显示不可用提示 |
| 旧帮助文章 `#article` 链接点击目录丢失文章 | 章节链接同时保留文章查询参数与章节片段 |
| 通用返回会丢帮助章节、跳过 AI 工作空间；修饰键被拦截 | 支持新工作空间路径和 hash，保留浏览器 Ctrl/Meta/Shift/Alt 点击行为；无 Provider 时也使用路由导航 |
| 同一标签页切换账号后仍可能返回旧身份的会话 | 返回历史按账号和当前角色隔离，仅保存允许的来源字段，不保存正文或草稿 |
| 慢速返回检查覆盖用户后续主动导航 | 页面、身份或返回请求已变化时，丢弃晚到的检查结果 |

## 页面覆盖清单

| 页面组 | 路由及检查点 |
| --- | --- |
| 工作台和全局入口 | `/`，主导航/移动导航/模块导航、任务抽屉和通知定位、面包屑和返回 |
| AI 和 Agent | `/ai-workspace`、其维护 Agent 子路径、旧 `/agents` 和维护深链；会话/草稿保留、业务页签、通知参数、返回和刷新 |
| 知识 | `/knowledge`、`/knowledge/:id`、`/my/knowledge`、`/knowledge-maintenance`、`/company-governance`；列表来源、详情、筛选、删除与维护 |
| 上传 | `/upload`，个人/项目/全局入口，待处理与历史任务，上传后查看审批状态 |
| 项目 | `/projects`、`/project/:id`、`/project/:id/knowledge`、`/project/:id/settings`；项目目录、搜索、问答、资料、上传、设置、删除 |
| 审批和授权 | `/review`、`/review/completed`、`/original-access`、`/original-access/grants`；目标对象、收件箱/本人申请、项目筛选和关闭详情 |
| 管理 | `/admin` 及 ingest、weknora-models、audit、auth-security、alert-settings、people、company-kb、naming-rules、permissions、release-notes；能力守卫、管理菜单、别名、作业和模型通知深链 |
| 帮助和更新 | `/help`、`/release-notes`；帮助文章、目录锚点、更新日志管理返回 |
| 账号和工具 | `/login`、`/my/workbuddy`、`/mcp-authorize`；登录后返回原站内地址、OAuth 外跳和返回、不允许外部返回路径 |
| 异常路径 | 未知路由、资源删除、权限撤销、数据读取失败、不可用历史任务；显示明确状态并提供可用出口 |

## 回归验证

- 路由注册/能力守卫/API 所属关系门禁支持嵌套路由；历史路由以兼容入口保留。
- 页面测试覆盖筛选和页码恢复、浏览器 POP、完成任务详情、目标作业定位、上传历史的所有者隔离和失效目标反馈。
- 上传提醒按实际本地/企业微信任务来源定位；不会因为入口缺少来源参数而强制进入本地上传。
- AI 工作空间浏览器测试覆盖 320、390、768、1024、1440 像素宽度及低高度窗口，检查 Agent 同页进入、返回、浏览器历史和未保存草稿。
- 维护 Agent 浏览器测试继续覆盖正常、空态、失败、无权、初始配置、只读、模型缺失/错误和旧巡检记录。
- 全站浏览器验收由 `scripts/global-frontend-acceptance.ui-qa.mjs` 汇总，检查各路由的具体状态与截图证据；产物保留在本地临时目录或 CI artifact，不提交用户资料或验收原始数据。

本次后端仅增加已有鉴权查询的可选定位条件和任务投影字段，不涉及数据库结构迁移。
